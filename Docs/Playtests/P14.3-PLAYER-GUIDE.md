# 《套马的汉子》P14.3 测试玩家教程

感谢你参加灰盒原型测试。画面和声音仍是临时版本；这次主要测试骑马追逐、从马群中切出目标、投掷套索、控绳和把马带回营地是否容易理解、是否值得重复练习。

## 1. 安装与启动

1. 将收到的 ZIP **完整解压**到一个普通可写目录，例如桌面或文档。不要直接在压缩包里运行，也不要只复制 EXE。
2. 打开解压后的目录，双击 `Steppe.exe`。
3. 第一次启动可能稍慢。看到草原、骑手和任务 HUD 后即可开始。
4. 默认目标是在倒计时结束前捕获一匹野马、让它接受接触、牵回营地并命名。

若无法启动，请记录屏幕上显示的原始错误文字，并联系测试组织者；不要自行删除文件或改配置。

## 2. 按键表

| 按键 | 作用 | 使用时机 |
| --- | --- | --- |
| `W / S` | 催马前进 / 减速 | 骑乘时 |
| `A / D` | 向左 / 向右带缰转向 | 骑乘时 |
| `W / A / S / D` | 前进 / 左移 / 后退 / 右移 | 徒步时；按 S 保持朝向后退 |
| 鼠标 | 转动观察方向 | 始终 |
| `Shift` | 加速冲刺 | 骑乘时会消耗马匹体力；徒步时切换为跑步 |
| `Ctrl` | 主动刹车 | 骑乘时 |
| `E` | 上下马、接触野马、拿起牵绳 | 根据当前情境 |
| `Q` | 选择或取消关注一匹野马 | 35 米内出现黄色选择框时；目标超过 42 米会自动取消 |
| 按住鼠标右键 | 显示套索环、摆动并瞄准；再次按下可主动解套 | 选中目标后瞄准；绳索附着后按下则释放野马 |
| 鼠标左键 | 投出套索；附着时也可松绳 | 右键瞄准时或绳索已经附着时 |
| `Space` | 稳绳/控绳 | 套索附着后 |
| `C` | 确认捕获 | 目标已被控制后 |
| `F1` | 开关开发调试信息 | 测试时保持关闭，除非组织者要求 |
| `F2` | 立即重新开始一轮 | 本轮失败、卡住或想重试时 |

## 3. 完整一轮怎么玩

### 第一步：找到并选择目标

骑向远处的十二匹野马。它们受惊后通常会沿共同方向成群奔跑，偶尔会有一匹落后或脱离。用鼠标让一匹马进入画面中央的黄色 `Q SELECT` 框，再按一次 `Q`。选中后框会变为青色并显示距离。再次对同一匹马按 Q 可以取消；目标离玩家超过 42 米时也会自动取消，需要追近后重新选择。

### 第二步：把目标切离马群

不要只从正后方一直追。尝试从目标与马群之间或侧后方施加压力，使这匹马逐渐远离其他马。当目标离其余马群中心达到约 10 米并保持约 1 秒，HUD 会提示目标已经 isolated/可投索。

如果整群都向同一方向跑，放慢一点，改变接近角度，再从侧面处理目标。

### 第三步：摆绳并投掷

选中目标后就可以按住鼠标右键查看套索环。灰环表示目标还没有切离马群；红环表示目标超过约 26 米套索射程；橙环表示可以继续摆动；环口打开并变绿时，用鼠标左键投出。

投出的绳圈会向前飞行、受重力下落并在前几米逐渐展开，所以仍需要判断方向、距离、瞄准高度和提前量。Q 只标记你想追的马；真正套中哪一匹取决于哪匹马实际进入三维绳圈，误套旁边的马也会形成有效结果。脱靶、撞到障碍或飞出射程时，套索会自动回收，稍等即可再次尝试。

### 第四步：控制张力

套中后中央会出现绳索对抗卡。按住 `Space` 稳绳，观察 `TENSION` 白色指针和 `CALMING` 进度：

- 张力太低时中央显示 `ROPE SLACK`，适当与目标拉开距离。
- 绿色有效区间会稳定增加控制进度。
- 张力过高时中央显示野马正在强拉。顺着它移动并逐渐调回绿色，不要在双方高速分离时突然刹停；急停冲击才可能断绳。
- 侧向拉力过大时会出现红色失衡警告；减速或让坐骑朝绳索方向转。
- 如果被拉下马，玩家会短暂倒地拖行，随后站起来继续握绳。使用 `W/A/S/D` 和 `Shift` 跟着野马跑，同时继续按住 `Space` 控绳；决定放弃时按鼠标右键解套。
- 被套野马一开始就比正常逃跑更慢；每次有效紧绳都会永久降低本次挣扎的速度上限，即使张力稍后变松也不会重新恢复全速。
- 绳索穿过树干、柱子等障碍时会形成一个橙色弯折点。障碍会承担一部分拉力并进一步限制野马速度；移到绳线重新畅通的位置后，弯折会自动解除。
- 主动下马后若绳索仍附着，野马也会拉着徒步玩家移动。靠近到 3 米内、跟上它的速度并持续按住 `Space` 约 2.5 秒，中央 `SURRENDER` 会逐渐填满；完成后野马立即归顺并进入牵行，不再自己挣扎逃跑。

骑乘控绳时，当 HUD 显示目标已 subdued/controlled，仍可按 `C` 走常规捕获路线。徒步贴近完成 `SURRENDER` 后会自动完成捕获和第一次接触，不需要再按 `C`。

### 第五步：下马并安全接近

如果你骑乘控绳并用 `C` 完成捕获：减速停稳，按 `E` 下马。慢慢走向刚捕获的马；快速冲过去会让它拒绝接触。靠近后停住，让它平静，等 HUD 提示 `Press E for first contact`，按一次 `E`。

如果你已经在徒步状态完成 `SURRENDER`，这一阶段已经自动完成，可直接牵马返回营地。

如果它退开或提示 give space，先停下或后退，等压力消退后再慢慢接近。

### 第六步：牵回营地并命名

常规 `C` 捕获路线在完成安全接近后，靠近野马按一次 `E`，即完成第一次接触并拿起牵绳。`SURRENDER` 路线会自动握住牵绳。可以步行返回，也可以靠近自己的坐骑按 `E` 上马慢骑；野马会跟随。骑乘牵行时冲刺会被限制，距离过大时坐骑会自动停下等待野马赶上。带它进入出生点标有 `CAMP / PEN` 的围栏交付区域。

Horse Card 出现后输入名字并确认。看到 `ROUND COMPLETE / HORSE NAMED` 即完成一轮。按 `F2` 开始下一轮。

## 4. 三轮测试怎么进行

你需要连续尝试三轮。可以失败，不要为了得到好成绩隐藏问题。

- **Round 1：** 按本教程自行尝试；组织者尽量不提示。
- **Round 2：** 根据第一轮经验调整追逐路线、出手时机或控绳方式。
- **Round 3：** 尝试证明自己是否已经学会，并可主动选择另一种马或不同路线。

每轮结束后先不要马上按 F2。告诉组织者：

1. 你认为这一轮为什么成功或失败。
2. 你是否愿意立即再玩一轮。
3. 骑马、追逐、切马、投索、拉扯、捕获后流程中，哪一段最困难。
4. 这一轮有没有发生值得复述的意外。

组织者记录完成后再开始下一轮。

## 5. 卡住时怎么办

- **找不到野马：** 从出生方向向开阔草地观察，寻找十二匹马组成的马群。
- **Q 没反应：** 追到 35 米内，让目标进入黄色选择框后再按 Q。超过 42 米的旧目标会自动取消。
- **套索环是灰色：** 目标还没有离群约 10 米；继续从侧后方把它切开。
- **套索环是红色：** 目标超过约 26 米射程；先追近，不要投掷。
- **总是套不中：** 更靠近、从目标运动方向预留提前量，并考虑绳圈飞行中的下落；等绿色 OPEN 窗口再投。
- **套中了另一匹马：** 这是物理绳圈的有效结果；Q 目标不会替绳圈自动吸附，出手前确认环的飞行路径中没有其他马穿过。
- **突然断绳：** 这通常来自野马高速远离时玩家突然刹停。顺着野马跑一段再逐渐减速，或把坐骑转向绳索方向。
- **下马后被野马拉着走：** 这是预期行为；用移动键和 Shift 跟跑并按住 Space，把张力调入绿色。再次按鼠标右键会主动解套。
- **套住后野马一直挣扎：** 徒步靠近到 3 米内、避免与野马高速反向移动，并持续按住 Space，等待 `SURRENDER` 填满。
- **下马后追不上：** 保持 W 朝野马方向跟跑并持续按住 Space。绳索拉力会帮助你向前，被套野马的速度上限会随着紧绳继续下降。
- **绳索绕到障碍上：** 橙色弯折点表示障碍正在增加阻力。可利用它靠近野马，也可绕开障碍让绳线恢复直线。
- **C 没反应：** CONTROL 尚未完成；继续保持有效张力。
- **不能接触：** 必须先下马、放慢、靠近后停住等待。
- **马不跟随：** 常规 C 捕获路线需先徒步安全接近，再靠近野马按一次 E；SURRENDER 完成后应立即跟随。骑乘牵行请慢骑并留意野马是否落后。
- **骑乘时前方有障碍：** 继续用 A/D 选定绕行方向。马匹会在近距离辅助偏转和减速，但不会自动寻路。
- **任务完全无法继续：** 按 F2 重开，并告诉组织者你在哪一步卡住。

## 6. 测试数据与隐私

游戏会在本机记录每轮阶段时间、投索次数、命中/脱靶/断绳、张力风险、落马、结果和积分。记录不包含姓名、联系方式、录音、视频或系统文件。

测试结束后按组织者说明运行结果收集脚本。Windows Shipping 包的记录位于 `%LOCALAPPDATA%\Steppe\Saved\Playtests`；也可以将其中本次产生的 `Round-*.json` 交给组织者。只使用匿名编号，例如 `T03`。
