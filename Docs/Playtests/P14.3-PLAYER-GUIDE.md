# 《套马的汉子》P14.3 测试玩家教程

感谢你参加灰盒原型测试。画面和声音仍是临时版本；这次主要测试骑马追逐、从马群中切出目标、投掷套索、控绳和把马带回营地是否容易理解、是否值得重复练习。

## 1. 安装与启动

1. 将收到的 ZIP **完整解压**到一个普通可写目录，例如桌面或文档。不要直接在压缩包里运行，也不要只复制 EXE。
2. 打开解压后的目录，双击 `Steppe.exe`。
3. 第一次启动可能稍慢。看到草原、骑手和任务 HUD 后即可开始。
4. 默认目标是在倒计时结束前捕获一匹野马、让它接受接触、牵回营地并命名。

若无法启动，请记录屏幕上显示的原始错误文字，并联系测试组织者；不要自行删除文件或改配置。

## 2. 按键表

| 按键 | 作用 | 使用时机 |
| --- | --- | --- |
| `W / S` | 催马前进 / 减速 | 骑乘时 |
| `A / D` | 向左 / 向右带缰转向 | 骑乘时 |
| 鼠标 | 转动观察方向 | 始终 |
| `Shift` | 加速冲刺 | 骑乘时；会消耗体力 |
| `Ctrl` | 主动刹车 | 骑乘时 |
| `E` | 上下马、接触野马、拿起牵绳 | 根据当前情境 |
| `Q` | 选择或取消关注一匹野马 | 看向马群时 |
| 按住鼠标右键 | 摆动并瞄准套索 | 目标已经切出后 |
| 鼠标左键 | 投出套索；附着/拖行时松绳 | 右键瞄准时或绳索已经附着时 |
| `Space` | 稳绳/控绳 | 套索附着后 |
| `C` | 确认捕获 | 目标已被控制后 |
| `F1` | 开关开发调试信息 | 测试时保持关闭，除非组织者要求 |
| `F2` | 立即重新开始一轮 | 本轮失败、卡住或想重试时 |

## 3. 完整一轮怎么玩

### 第一步：找到并选择目标

骑向远处的五匹野马。用鼠标让一匹马处于视野前方，按 `Q` 选中。HUD 会显示目标和切出进度。Q 只是当前关注目标；再次按 Q 可以取消或更换。

### 第二步：把目标切离马群

不要只从正后方一直追。尝试从目标与马群之间或侧后方施加压力，使这匹马逐渐远离其他马。保持一段时间，直到 HUD 提示目标已经 isolated/可投索。

如果整群都向同一方向跑，放慢一点，改变接近角度，再从侧面处理目标。

### 第三步：摆绳并投掷

目标切出后，看向它并按住鼠标右键。观察 `SWING/OPEN` 稳定窗口；环口打开、提示变绿时，用鼠标左键投出。

投掷仍需要判断方向、距离和提前量。脱靶、撞到障碍或目标离得太远时，套索会自动回收，稍等即可再次尝试。

### 第四步：控制张力

套中后按住 `Space` 稳绳。观察 `TENSION`、`CONTROL`、`BALANCE` 和 `SIDE`：

- 张力太低，控制进度很慢。
- 绿色有效区间会稳定增加控制进度。
- 橙红色张力持续过高会断绳。
- 侧向拉力过大时，应减速或让坐骑朝绳索方向转，避免失去平衡。
- 如果落马并被短暂拖行，鼠标左键可以立即松绳。

当 HUD 显示目标已 subdued/controlled 时，按 `C` 确认捕获。

### 第五步：下马并安全接近

减速停稳，按 `E` 下马。慢慢走向刚捕获的马；快速冲过去会让它拒绝接触。靠近后停住，让它平静，等 HUD 提示 `Press E for first contact`，按一次 `E`。

如果它退开或提示 give space，先停下或后退，等压力消退后再慢慢接近。

### 第六步：牵回营地并命名

第一次接触完成后，再按一次 `E` 拿起牵绳。步行返回标有 `CAMP / PEN` 的出生点围栏，让野马跟着你进入交付区域。

Horse Card 出现后输入名字并确认。看到 `ROUND COMPLETE / HORSE NAMED` 即完成一轮。按 `F2` 开始下一轮。

## 4. 三轮测试怎么进行

你需要连续尝试三轮。可以失败，不要为了得到好成绩隐藏问题。

- **Round 1：** 按本教程自行尝试；组织者尽量不提示。
- **Round 2：** 根据第一轮经验调整追逐路线、出手时机或控绳方式。
- **Round 3：** 尝试证明自己是否已经学会，并可主动选择另一种马或不同路线。

每轮结束后先不要马上按 F2。告诉组织者：

1. 你认为这一轮为什么成功或失败。
2. 你是否愿意立即再玩一轮。
3. 骑马、追逐、切马、投索、拉扯、捕获后流程中，哪一段最困难。
4. 这一轮有没有发生值得复述的意外。

组织者记录完成后再开始下一轮。

## 5. 卡住时怎么办

- **找不到野马：** 从出生方向向开阔草地观察，寻找五匹马组成的小群。
- **Q 没反应：** 让目标位于画面中央并靠近一些，再按 Q。
- **不能摆绳：** 先完成切出；HUD 必须提示目标已 isolated。
- **总是套不中：** 更靠近、从目标运动方向预留提前量，并等绿色 OPEN 窗口。
- **一直断绳：** 不要持续全速背向目标，减速并朝绳索方向转。
- **C 没反应：** CONTROL 尚未完成；继续保持有效张力。
- **不能接触：** 必须先下马、放慢、靠近后停住等待。
- **马不跟随：** 第一次接触后需要再按一次 E 拿起牵绳。
- **任务完全无法继续：** 按 F2 重开，并告诉组织者你在哪一步卡住。

## 6. 测试数据与隐私

游戏会在本机记录每轮阶段时间、投索次数、命中/脱靶/断绳、张力风险、落马、结果和积分。记录不包含姓名、联系方式、录音、视频或系统文件。

测试结束后按组织者说明运行结果收集脚本。Windows Shipping 包的记录位于 `%LOCALAPPDATA%\Steppe\Saved\Playtests`；也可以将其中本次产生的 `Round-*.json` 交给组织者。只使用匿名编号，例如 `T03`。
