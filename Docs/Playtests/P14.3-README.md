# P14.3 人工试玩执行包

## 每名测试者的流程

1. 分配匿名编号 `T01`–`T05`，不要记录姓名或联系方式。
2. 告知玩家目标：“从马群中套住一匹野马，让它接受你，牵回营地并命名。”不要额外演示解法。
3. 确认 F1 开发调试信息关闭；游戏内基础按键提示保持可见。
4. 让玩家连续尝试 3 轮。观察者不在轮内纠正，只有完全无法继续时才帮助，并把帮助记为 Blocker/Clarity 观察。
5. 每轮结束后填写 `P14.3-Round-Log.csv` 一行，并记录对应 `Saved/Playtests/Round-*.json` 文件名。
6. 每名玩家结束后，用 `P14.3-Session-Notes.md` 做 3–5 分钟访谈。

## 四段核心体验评分

每段使用 1–5 分：1 表示输入与结果几乎没有关系，3 表示能完成但不稳定或不清楚，5 表示可控、可学习且愿意继续练习。

- **Ride：** 加速、刹车、转向和重量感。
- **Isolate：** 选马、判断群体位置和把目标切出。
- **Throw：** 摆绳、瞄准、出手时机和命中理解。
- **Rope：** 张力、方向、风险和恢复。

## 数据汇总

自动记录放在 `Saved/Playtests/`。运行：

```powershell
.\Scripts\SummarizePlaytests.ps1
```

脚本默认只汇总明确包含 `isAutomated=false` 的真人试玩 JSON，排除自动 Smoke 和旧版无标记记录，输出 `Saved/Playtests/P14.3-Aggregate.csv`。访谈和主观评分由 `P14.3-Round-Log.csv` 单独保留，分析时用 MetricFile 关联。
