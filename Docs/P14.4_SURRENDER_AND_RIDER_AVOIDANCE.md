# P14.4 自然降伏与骑乘避障辅助

本增量回应两条真人试玩反馈：被套野马在玩家徒步贴近并持续控绳后仍自行逃跑；玩家坐骑在有明确转向输入时仍会正面撞上近距离障碍。

## 徒步自然降伏

套索处于 Attached，骑手已经下马或被拉下马时，同时满足以下条件会推进 `OnFootSurrenderProgress`：

- 骑手持续按住 `Space`；
- 骑手与目标二维距离不超过 300 cm；
- 双方沿绳方向的分离速度绝对值不超过 260 cm/s；
- 条件持续累计约 2.5 秒。

条件短暂失效时进度会衰减。完成后 LassoComponent 通过 HerdManager 一次性登记捕获，并由 HorseTrust 进入 Leading：`CapturedHorses`、`FirstContactHorses`、`LeadingHorse`、HorseBrain 的 Captured/LeadTarget 和套索 Captured 状态在同一次流程中更新。野马停止独立挣扎，改为跟随徒步玩家。HUD 用 `SURRENDER` 进度和 `HORSE SURRENDERED | LEAD IT TO CAMP` 明确反馈结果。

骑乘状态下原有 `ControlProgress → Subdued → C → 安全接近 → E → E` 路线继续有效，便于比较两种体验。

## 骑乘障碍辅助

HorseMovement 只在骑手控制、前进意图有效且坐骑接地时启用辅助。组件以当前转向意图为基准，从马身前方发出中心、左前和右前三个球形探针：

- 探测距离随速度增加，基准 550 cm；
- 探针半径 55 cm，左右偏角 32 度；
- 中心受阻时优先选择可通行的一侧；
- 两侧结果接近时沿用上一帧方向，避免左右抖动；
- 辅助转向强度上限为 0.65，骑手强输入仍会保留；
- 遇障会降低目标速度，两侧都阻塞时额外制动。

辅助只改变进入现有 HorseMovement 响应层的意图。碰撞、滑动、速度积分和最终朝向仍由 CharacterMovement 与既有运动规则处理。

## 验证重点

人工试玩应确认：

1. 被拉下马后，玩家能从 HUD 理解要靠近、跟速并持续按住 Space。
2. `SURRENDER` 完成时野马立即转为跟随，不再沿原逃跑意图移动。
3. 骑手朝障碍前进时能感到轻微偏转和减速，同时仍能用 A/D 决定绕行方向。
4. 狭窄死路不会伪装成自动寻路；玩家仍需要刹车或掉头。
