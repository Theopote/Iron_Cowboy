# P14.3 Windows 打包与分发

## 一键打包

关闭 Unreal Editor，然后在项目根目录打开 PowerShell：

```powershell
.\Scripts\PackageWindows.ps1 -EngineRoot 'C:\Program Files\Epic Games\UE_5.8' -Clean -Zip
```

脚本会使用 UE 5.8.2 执行 Win64 Shipping 的 Build、Cook、Stage、Pak 和 Archive，只烘焙原型草原地图，并包含运行所需的 prerequisites。输出位于：

```text
Packages/ProjectSTEPPE-Windows/
Packages/ProjectSTEPPE-Windows-YYYYMMDD-HHMM.zip
Packages/ProjectSTEPPE-Windows-YYYYMMDD-HHMM.zip.sha256.txt
```

ZIP 内同时包含：

- 完整 Windows 游戏文件。
- `PlaytestKit/P14.3-PLAYER-GUIDE.md`。
- `PlaytestKit/P14.3-ORGANIZER-GUIDE.md`。
- `PlaytestKit/P14.3-Round-Log.csv`。
- `PlaytestKit/P14.3-Session-Notes.md`。
- `Tools/CollectPlaytestResults.ps1`。

## 打包参数

不需要 ZIP 时省略 `-Zip`。输出目录已有内容时脚本会停止；确认要替换旧包时使用 `-Clean`。也可以指定目录：

```powershell
.\Scripts\PackageWindows.ps1 `
  -EngineRoot 'C:\Program Files\Epic Games\UE_5.8' `
  -OutputDirectory 'D:\Builds\STEPPE-Test-01' `
  -Clean -Zip
```

`-Clean` 只会删除解析后的指定输出目录，脚本会拒绝项目根目录、磁盘根目录或过短路径。

## 发给测试者

1. 自己先把最终 ZIP 解压到一个新目录，运行 `Steppe.exe` 做一次启动检查。
2. 发送整个 ZIP和同名 `.sha256.txt`；不要单独发送 EXE、Paks 或 DLL。
3. 同时给测试者分配 TesterId，例如 `T01`。
4. 要求对方完整解压，阅读 `PlaytestKit/P14.3-PLAYER-GUIDE.md` 后运行。
5. 三轮结束后运行 `Tools/CollectPlaytestResults.ps1`，把生成的结果 ZIP 发回。

当前包是无安装器、未签名的 Windows 灰盒测试版。测试者应只使用你直接提供且文件名一致的 ZIP。若系统或组织策略阻止运行，不要求测试者绕过安全策略；改用受信任的传输、签名或现场测试电脑。

## 每次发包前检查

- 文件名带日期或测试批次，避免测试者运行旧版。
- `Steppe.exe` 能从全新解压目录启动。
- 默认地图是草原原型关卡。
- F2 能重新开始，命名后能正常结算。
- `PlaytestKit` 和 `Tools` 存在。
- 玩一轮后能够找到 `Round-*.json`，收集脚本能生成结果 ZIP。
- 不把 `Saved/`、源码、`.idea/`、开发日志或旧测试数据放入分发包。
- 共用测试电脑时，每位玩家三轮结束后立即运行收集脚本；脚本只选择最新三轮。
