# P16.5 骑手与挂点集成记录

## 当前可验证结果

- 临时骑手采用本机 UE 5.8 模板 Mannequin 网格、骨架及 Idle/Walk/Run/Jump Loop 动画。资源放在 `/Game/Mannequin/`，保留模板原有引用路径。模板资源受 Unreal Engine EULA 约束，只用于本 Unreal Engine 项目；替换正式美术前需再次核对分发条件。
- `RiderSeat` 挂在马的 Body 骨；`LassoHand_R`、`Rein_L`、`Rein_R` 挂在骑手手骨；马的 Head、Neck、Chest 也有骨骼挂点。`Scripts/ConfigurePresentationSockets.py` 可重复核对配置；首次修复骨骼绑定时使用 `RunEditor.ps1 -PythonScript ... -ExtraArgs -SteppeFixSockets`。脚本会拒绝名称正确但骨骼错误的挂点。
- 徒步骑手按速度播放临时 Idle/Walk/Run。骑乘使用生成的 `RiderMounted_Pose`：保留 Idle 的直立根骨/躯干，双腿取 Jump Start 的对称弯膝、手臂取 Jump Loop 的弯曲姿态，并将网格下沉 35 cm 让髋部落在马背。马身骨的倾斜局部坐标只用于座位位置，骑手世界朝向取坐骑朝向。落马和拖行另用 Jump Loop。
- 骑乘腿部不再使用 Jump Loop 的非对称单腿收起帧；双腿改取 Jump Start 起始帧约 90° 的对称膝弯。基础坐姿、摆索、骑乘投掷和骑乘稳绳共用该腿部基线，自动测试要求双脚跨在马体中心线两侧且高度接近。
- 投索发射点和显示绳索使用手部挂点。`RopeStart` 保持稳定的玩法锚点，`VisualRopeStart` 随骨骼手部移动；张力、绳长和绕障碍判定不依赖手部动画。这样更换骑手动画不会暗改套索难度。
- 骑乘瞄准使用四个离散摆索相位；Lasso 进入 Thrown 后切换到骑乘投掷姿态，附着并按住控绳时切换到骑乘稳绳姿态。玩家下马后，对应使用徒步投掷和徒步稳绳姿态，让“仍握着绳并与野马对抗”在画面中保持连续。
- 骑乘瞄准暂用四个右肩/手臂灰盒姿态读取 Gameplay `SwingPhase`，使 `LassoHand_R` 围绕身体产生可见移动。它只改变表现，不决定稳定度、环口或命中。
- `ABP_Rider` 现在把 `DefaultSlot` 的骑乘/徒步基础姿态与独立 `UpperBodySlot` 通过 `spine_01` 分层混合。摆索、投掷和稳绳只覆盖上半身；骑乘腿部持续使用同一个对称坐姿。两个 Slot 登记在不同 Montage 组，避免套索动作中断基础坐姿。`URiderAnimInstance` 负责 0.12–0.14 秒混合，Gameplay 仍负责选择状态和摆索相位。
- 主动上下马的安全判定和 Gameplay 状态切换仍即时完成；可见骑手网格另以短时缓动经过座位和落地点，减少状态瞬切。位移有 180 cm 上限，意外落马沿用原摔落流程。
- 套索附着后，表现数据从实际绳索第一段计算 `RopeYaw`：直连时朝目标，绕障碍时朝弯折点。骑手以有限角度随该方向扭身，并按 `RopeTension` 后仰和侧倾；这些值不写回 Gameplay。
- 灰盒缰绳从 `Rein_L/Rein_R` 手部挂点连接马的 `Head` 挂点。正常骑乘显示双缰；右手进行套索动作时只显示左缰。双脚继续由 Mannequin 的 `foot_l/foot_r` 骨骼提供接触位置，当前用于校准和自动回归，尚未引入脚部 IK。
- `FRiderPresentationData` 暴露移动速度、骑乘、瞄准、摆索相位/稳定度、撑绳、摔落、拖行、牵马、身体倾斜和座位起伏，供后续动画层读取。
