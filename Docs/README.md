1. `GAME_DESIGN_VISION.md`：长期产品方向与设计支柱。

5. `P12_LASSO_SKILL_SPEC.md`：当前套索摆绳、稳定性、命中区域、骑手平衡、落马与拖行规格。
6. `P13_AUDIO_VISUAL_SPEC.md`：当前反馈信号、程序化占位音、马蹄/尘土与绳索风险表现规格。
7. `P14_PLAYTEST_VALIDATION.md`：逐轮指标字段、人工试玩步骤、问题分类和 Go 条件。
8. `P11_HORSE_ARCHETYPES_SPEC.md`：三类野马原型及 Gameplay 接入规格。
9. `P10_LEAD_DELIVERY_NAMING_SPEC.md`：完整闭环的牵行、交付和命名规格。
10. `DESIGN_DECISIONS.md`：已确认决策、待决事项和变更记录。
