# 《套马的汉子》游戏设计愿景

## 产品定义

《套马的汉子》是一款以第三人称骑乘、野马追逐、群体操纵和套索对抗为核心的草原游戏。长期方向可以扩展到马匹关系、牧场经营、迁徙与生态，但产品成立的前提始终是：不依赖剧情或奖励，单纯骑马追逐并控制一匹野马也值得反复玩。

玩家幻想不是“拥有一辆马形载具”，而是在高速运动、混乱和不可预测中读懂动物与环境，并重新控制局面。熟练玩家应通过路线、节奏和判断提高成功率，而不是依赖更高的数值或自动锁定。

## 三个设计支柱

### 马是动物

- 输入表达骑手要求，马的响应、惯性、体力和处境决定真实运动。
- 野马会观察接近方向与速度，会寻求群体保护，也会因个体差异产生不同反应。
- 捕获只改变眼前局面；建立信任和形成长期关系需要后续互动。

### 草原是系统

- 地形、空间、天气、季节、资源和其他动物最终都应改变玩法，而不只是提供背景。
- 玩家位置对马群形成压力，能够驱赶、分流和切出目标。
- 长期内容应由生态规则产生变化和故事，避免把世界简化为任务图标集合。

### 套索是工具

- 投掷需要时机、角度、提前量和距离判断，不是射线武器或按键判定。
- 套中是对抗的开始：张力、相对速度、目标反抗和玩家路线共同决定结果。
- Gameplay 判定与绳索视觉分离，以保证手感可控、结果可解释，并为未来物理表现和网络同步留出空间。

## 核心体验循环

```text
观察马群 → 选择目标 → 接近并施压 → 切出目标
→ 投掷套索 → 管理张力与路线 → 控制目标
→ 安全接近 → 建立第一次信任 → 牵回营地 → 命名
```

当前工程已经实现到“控制并登记捕获”，后半段的安全接近、信任、牵行、营地返回和命名是下一阶段的主要缺口。

## 体验目标

- 骑马本身具有重量、速度和可学习的转向节奏。
- 玩家能够解释马为什么警觉、逃跑、回群、挣扎或停下。
- 失败让玩家产生“下一次能做得更好”的判断，不归因于随机判定。
- 马群看起来由个体组成，但会传播警报、聚散和共同改变方向。
- 每次捕获允许出现不同路线、失误和险情，形成可复述的玩家故事。

## 风格与氛围

- 视觉方向：写实环境与动物重量感，人物反馈可以略带夸张；关键词为辽阔、风、草浪、尘土、云影、夕阳和奔腾马群。
- 声音方向：日常保持克制，以风、马蹄、呼吸和环境声建立空间；追逐与失控时再逐步加入音乐。
- 语气可以豪迈并带自然喜剧，但不削弱动物与环境的可信度。

## 长期候选方向

马匹年龄、性格、关系、血统、育种、牧场、草场轮牧、季节、迁徙、狼群、竞技、动态故事和多人协作都与愿景相容。它们目前属于产品储备，不是已批准的近期范围。只有核心原型通过重复游玩门槛后，才逐项立项。

## 功能判断标准

新增功能至少应明显强化以下一项：骑乘手感、读马与读群、套索技巧、失败可解释性、动物个体感、系统故事密度。仅增加内容数量、地图面积或数值层级，而不强化这些体验的功能应推迟。
