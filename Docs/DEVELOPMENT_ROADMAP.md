# Project STEPPE 后续开发路线图

## 当前起点

工程基线已通过 P14.3 人工阶段门，并完成 P14.4 Core Feel。项目负责人于 2026-09-22 正式验收 P15 与 P16 第一轮；P16.5 条件通过，仅剩 Finalization，随后进入 P16.6 Grassland Gameplay Vertical Slice。

里程碑编号从 **P9** 延续现有工程历史；它不等同于早期讨论稿的阶段编号。

## P9 — 捕获后安全接近

**状态：已完成。** 实现与验证记录见 `P9_CAPTURE_AFTERMATH_SPEC.md`。

**目标：** 捕获不再是按钮后的终点，玩家需要下马并让目标接受第一次接触。

范围：

- 将 Captured 结果拆分为 Controlled、Approaching、Trusted/Captured 等可解释状态。
- 目标读取玩家距离、步行速度、正面冲入和停顿时间。
- 过快靠近会让目标后退、增加压力或暂时拒绝接触；缓慢靠近和适时停顿降低压力。
- 使用上下文交互完成第一次触摸，并记录最低限度 Trust 结果。
- HUD 给出行为提示，视觉实现可继续使用灰盒。

退出条件：

- 玩家不能在马上或高速冲向目标时直接完成信任。
- 至少存在一条可恢复的接近失败路线。
- 自动化测试覆盖速度/距离/停顿规则，实际试玩完成捕获后下马接近。

## P10 — 牵回营地与命名

**状态：已完成。** 实现与验证记录见 `P10_LEAD_DELIVERY_NAMING_SPEC.md`。

**目标：** 完成早期设计定义的第一条完整情感闭环。

范围：

- 建立 Lead 状态和牵引锚点；目标通过 Horse Intent 与 Movement 跟随。
- 增加营地/围栏交付区域和明确返回方向。
- 交付后显示 Horse Card：临时身份、性别/年龄占位、毛色、三到四项能力与性格词。
- 支持输入名字、确认本轮结果和开始新一轮。
- 本轮内保存命名结果；跨启动持久存档另行立项。

退出条件：

- 玩家无需控制台或调试操作即可完成营地出发到命名。
- 牵行目标不会瞬移、穿越主要障碍或重新加入活动马群。
- 重玩会清理旧任务对象；命名界面不会与骑乘输入冲突。

## P11 — 可感知的马匹个体差异

**状态：已完成。** 实现与验证记录见 `P11_HORSE_ARCHETYPES_SPEC.md`。

**目标：** 玩家描述“这匹马胆小/强壮/灵活”，而不是只看到编号不同。

范围：

- 建立至少 Fast、Strong、Nervous 三种测试 Archetype。
- Speed/Stamina/Fear/Strength/Agility 真实进入运动、威胁、张力和接近计算。
- Horse Card 只展示确实影响 Gameplay 的特征。
- 毛色或灰盒颜色提供最小识别，不把视觉差异当作行为差异证据。

退出条件：

- 盲测玩家能以高于随机的准确率辨认至少三种类型。
- 同一路线与操作对不同马产生可解释的时间、张力或逃跑差异。
- 参数全部数据驱动，测试不依赖硬编码资产路径。

## P12 — 套索技巧与失控后果

**状态：已完成。** 两次增量的规格与验证见 `P12_LASSO_SKILL_SPEC.md`。

**目标：** 提高投掷技术空间，并让过载产生可读且可传播的后果。

范围按两次增量交付：

1. **已完成：** 摆绳/准备节奏、动态投掷稳定性与 Head/Neck/Torso 简化命中区域。
2. **已完成：** Rider Balance、侧向拉力、Stumble/Fall，以及可主动松手的短距离 Dragged 状态。

退出条件：

- 连续练习能提高命中率，而自动锁定不能替代提前量判断。
- 不同命中位置影响控制风险，并有清晰反馈。
- 落马和拖行由确定性阈值触发，可恢复、可调试，不破坏角色生命周期。

如果这一阶段使结果更随机或更难解释，应保留现有稳定 Solver 并回退表现复杂度。

## P13 — 垂直切片音画

**状态：前三次增量已完成，正式资产可沿现有接口替换。** 反馈信号、程序化回退、双地表路由、Sound/Niagara 插槽、动画姿态数据、灰盒运动表现、动态绳索风险、Horse Card 与结算层级已经完成，规格与证据见 `P13_AUDIO_VISUAL_SPEC.md`。

**目标：** 用必要表现强化速度、动物状态和绳索风险，形成可对外演示的灰盒增强版。

优先级：

1. **已完成基础信号：** 马蹄节奏、速度风感、体力呼吸。
2. **已完成占位事件：** 套索摆动、飞行、拉紧、危险和断裂声音事件。
3. **已完成灰盒表现：** 追逐尘土、绳索受力与控制完成反馈。
4. **已完成数据与灰盒表现：** 马匹和骑手姿态接口已接入；真实骨架 AnimBP 待素材确定后替换。
5. **已完成：** Horse Card、命名、任务结果和结算 UI 层级。

退出条件：

- 关闭开发 HUD 后，玩家仍能判断速度、警觉、有效张力和危险张力。
- 表现缺失或资源替换不会改变 Gameplay 结果。
- 完整 6–10 分钟流程可录制、可重复且无明显占位信息遮挡。

## P14 — 原型验证门

**状态：阶段门已通过。** 累计真人反馈与诚实的数据限制见 `P14.3_GAMEPLAY_RESEARCH_REVIEW.md`；自动字段见 `P14_PLAYTEST_VALIDATION.md`。

**目标：** 用实际玩家行为决定是否扩大产品范围。

执行：

- **已完成：** 自动记录阶段耗时、投索结果、绳索/Balance 风险、结果、积分、重试与退出原因。
- 至少 5 名测试者，每人完成或尝试 3 轮。
- 记录 GDD 第 8 节指标，并访谈失败原因、个体辨识和重试意愿。
- 将问题按 Blocker、Core Feel、Clarity、Polish 分类。
- 先修复核心手感和可解释性，再决定是否进入长期系统。

Go 条件：多数测试者愿意立即重试；骑乘、切出、投索和控绳各有可学习空间；失败原因大体可复述；不同马有可感知差异。未满足时继续原型迭代，不开启开放世界或经济系统。

## P16 — Horse Dynamics v2

**状态：第一轮正式通过；后续真人手感复核仍按计划进行。** Heading 与 Velocity 已短时分离，前向/侧向速度、Slip Angle、Grass/Hard 抓地和有界绳索外力入口均已实现并自动验证。暂不继续扩大底层动力学或地表类型。实施边界见 `P16_HORSE_DYNAMICS_V2.md`。

## P16.5 — 马与骑手表现集成

**状态：Completed（2026-09-23）。** P16.5A 马动画、P16.5B 骑手骨骼、P16.5C 套索动画和 P16.5E 动力学表现已通过。现有 `ABP_Horse`、`ABP_Rider`、上半身分层、主动上下马视觉过渡及低速定向挣扎足够服务 Vertical Slice，不继续增加动作或重构动画架构。

P16.5D 仅补 RiderSeat、左右脚和左手缰绳的最低限度接触约束；右手套索动作保持自由。Gameplay 的座位、运动、碰撞、套索长度与张力继续保持权威。

Finalization 退出条件：

1. 完成最低限度接触约束，避免臀部漂浮、双脚穿马和左手明显离缰。
2. 完整走通骑马出发→追逐→选马→摆索→投索→拉扯→落马→徒步控绳→归顺→牵马→再上自己的马→骑乘牵马→营地命名的表现 Smoke。
3. 从玩家第三人称镜头检查 RiderSeat、马背遮挡、摆索手、绳索起点、缰绳与腿部穿插。
4. 26 项自动化测试、Editor Gameplay Smoke、最新 Win64 Shipping Build/Cook/Stage/Archive 及可执行文件启动 Smoke 均通过。
5. 在 `DEVELOPMENT_STATUS.md` 与本路线图标记 Completed。即使灰盒动作略僵也结束 P16.5；正式美术资产、Motion Matching 和高级 Horse IK 延后。

## P16.6 — Grassland Gameplay Vertical Slice

**状态：进行中。** 806.4 米单块 Landscape、平原/缓坡/小丘/浅谷/河床、营地与围栏、浅河减速、东侧硬地及岩石路线、西侧六棵可绕绳树、12 匹马 Habitat 分布已经进入关卡。3,184 个贴地草实例有材质风摆和距离裁剪。上坡减速并增耗，下坡略增速但降低制动与转向，浅河使马匹速度倍率为 0.62，硬地沿用已有抓地差异。自动化与编辑器闭环回归通过。

**剩余验收：** 实际第三人称完成营地至马群往返，记录草、坡、树、河、硬地中至少三项如何改变玩家路线或操作；确认草在近景与高速骑乘下的密度和扰动反馈，再决定是否补最小表现。关卡继续使用单块 Landscape，不启用 World Partition、PCG、HLOD、Mass 或完整生态。

退出条件：玩家从营地上马，找到并切出马群目标，完成追逐、投索、拉扯、捕获、牵回与命名；草、坡、树、河、硬地中至少三项实际改变玩家的路线或操作决策。只具装饰作用不算通过。

## P16.7 — 动画、音频与 VFX 收尾

**状态：等待 P16.6。** 用少量合规素材替换马蹄、呼吸、绳索受力、风、尘土和浅水水花的程序化占位；检查蹄部落地、骑手手脚约束和 Gameplay SwingPhase 到动画相位的同步。完成后进行第二轮正式真人试玩，再决定 P17。

## P17 — Living Horse / Ecology Foundation

**状态：冻结至第二轮试玩。** 只有 P16.5–P16.7 的可读表现和第二轮试玩证明核心体验成立后，才评估饥饿、饮水、疲劳、压力、社交需求、草场/水源与迁移。牧场、长期经济和育种另行立项。

## 验证纪律

每个里程碑都必须：

1. 在实现前写清范围、非目标和退出条件。
2. 保持 UE 5.8.2 Development 构建通过。
3. 为确定性规则添加必要测试，不用自动化替代手感验收。
4. 至少运行一条真实 Editor Gameplay 路径并保存日志/截图。
5. 更新 `DEVELOPMENT_STATUS.md`、相关 GDD 和决策记录。

## 暂缓清单

P14–P16 核心体验门通过前不启动：大地图、World Partition 生产化、12 匹以上性能专项、远距离 MassEntity、育种、经济、建造、季节、狼群、剧情任务、多人或持久在线服务。
